Política de Privacidad

Última actualización: 12 de mayo de 2026

Esta aplicación permite a los usuarios enviar correos electrónicos mediante su cuenta de Google utilizando la API de Gmail de Google LLC.

Datos a los que accede la aplicación

La aplicación puede acceder a:

Dirección de correo electrónico de la cuenta autenticada.
Datos necesarios para enviar mensajes de correo electrónico en nombre del usuario.

La aplicación no accede al contenido completo de la cuenta de Gmail salvo lo estrictamente necesario para la funcionalidad de envío de correos.

Uso de la información

La información obtenida se utiliza únicamente para:

Autenticar al usuario mediante Google.
Permitir el envío de correos electrónicos solicitado por el usuario.
Almacenamiento de datos

La aplicación no comparte datos con terceros.

Los tokens de autenticación pueden almacenarse localmente en el equipo del usuario para mantener la sesión iniciada.

Revocación de permisos

El usuario puede revocar el acceso de la aplicación desde:

https://myaccount.google.com/permissions
